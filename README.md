# vmo-algo

Some of my solutions to algorithmic problems

My compilation flags for c++:
```bash
g++ -g -O0 -std=c++20 -Wall -Wextra -Wshadow -fsanitize=address,undefined main.cpp -o main
```

And for C:
```bash
gcc -g -O0 -std=c17 -Wall -Wextra -Wshadow -fsanitize=address,undefined main.cpp -o main
```
